# Artigos (página Conteúdos)

Cada artigo é um arquivo `.mjs` nesta pasta. Para criar um novo, copie um
existente, troque o nome do arquivo e preencha os campos.

- `publicado: false` → o artigo só aparece na prévia. Mude para `true` depois
  que a Andréa revisar e aprovar o texto.
- `slug` → endereço do artigo (`/conteudos/<slug>/`). Sem acentos, só letras
  minúsculas, números e hífens. Não mudar depois de publicado.
- `imagem` → opcional. Arquivo em `site/static/img/artigos/`, horizontal
  1200×630, com `alt` descritivo. Nada de balança, fita métrica, antes/depois.
- Regras éticas: sem promessa de resultado, sem número de quilos, sem "cura",
  linguagem proporcional à evidência ("pode ajudar", "está associado").
